# Hi, I'm Jeff 👋

Accountant who builds AI tools for real accounting work: reconciliations,
document intake, and engagement management. My rule for every tool:
**the AI never invents a number, and a human approves anything that matters.**

### Accounting tools
- **[Hermes for Excel](https://github.com/lEWFkRAD/hermes-excel-sidecar)**: an AI chat pane inside Excel. It reads sheets for tie-outs and reconciliations, writes tables and formulas, re-checks what it wrote, and has Undo.
- **[Document Reader](https://github.com/lEWFkRAD/hermes-document-reader)**: watched-folder OCR for scanned PDFs and images, with readable exports.
- **[Engagement MCP Template](https://github.com/lEWFkRAD/engagement-mcp-template)**: one engagement, one folder. Deliverables, document requests, approval gates, and open items, with firm-internal items hidden from shared views.

### Other builds
- **[Hermes Notebook](https://github.com/lEWFkRAD/hermes-agents-guide-to-the-galaxy)**: handwriting-first AI notes on Kindle Scribe, BOOX, and Android tablets.
- **[hermes-android](https://github.com/lEWFkRAD/hermes-android)**: remote Android control for the Hermes agent.
- **[qwen38-rtx-pro-6000](https://github.com/lEWFkRAD/qwen38-rtx-pro-6000)**: reproducible local AI model deployments on a single workstation GPU, with benchmarks.

Most of my tools are plugins for [Hermes Agent](https://github.com/NousResearch/hermes-agent).
